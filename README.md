# DevOps Learning Journey & Production Runbooks

Welcome to my DevOps engineering repository. This repository serves as a practical, hands-on documentation hub for my 8-month journey toward becoming a Junior DevOps Engineer. It contains production-grade runbooks, server security configurations, disaster troubleshooting scenarios, and automation scripts.

---

## 🛠️ Environment & Tooling
* **Host OS:** CachyOS (Arch-based Linux, KDE Plasma)
* **Lab Environment:** Ubuntu Server (VPS / Local VM)
* **Workflow:** 100% Terminal & CLI-driven execution

---
